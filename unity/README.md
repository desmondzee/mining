# Unity

Unity 6.3 LTS project. Protocol and parameters: [../spec.md](../spec.md).

## Open

1. Fetch people models: `cd brain && uv run python ../tools/fetch_rocketbox.py` (or on watson: `docker run --rm --user $(id -u):$(id -g) -v "$PWD":/w -w /w mining-brain python tools/fetch_rocketbox.py`).
2. Unity Hub > Add > select this `unity/` folder; open with 6000.3.26f1.
3. Wait for packages (URP, glTFast) to resolve and the GLBs to import.
4. Tools > Mining > Build Quarry Scene (Quarry World), or flat ground: (Komatsu HD465) / (CAT 785C).
5. Optional: Tools > Mining > Capture Views writes camera, pedestrian and truck PNGs to `Captures/` (or `CAPTURE_DIR`).

Batch mode (no window):

```bash
UNITY=/Applications/Unity/Hub/Editor/6000.3.26f1/Unity.app/Contents/MacOS/Unity
$UNITY -batchmode -quit -projectPath "$PWD" -executeMethod QuarrySceneBuilder.BuildQuarry -logFile build.log
$UNITY -batchmode -quit -projectPath "$PWD" -executeMethod SceneCapture.Capture -logFile capture.log
```

Generated by the builder and gitignored: `Assets/Scenes`, `Assets/Prefabs`, `Assets/Generated`, `Assets/MineSim/Generated`.

| Entry point | Scene |
|---|---|
| `QuarrySceneBuilder.BuildQuarry` | scanned quarry (`data/worlds/quarry`), Komatsu, road crossings |
| `QuarrySceneBuilder.BuildKomatsu` | flat ground, rocks, Komatsu |
| `QuarrySceneBuilder.BuildCat` | flat ground, rocks, CAT 785C |

| Layer | Contents | Seen by |
|---|---|---|
| `MineDebug` (8) | site markers, junctions, road lines, labels | editor only (not truck/overview cameras, depth, lidar) |

## Layout

| Path | Contents |
|---|---|
| `Assets/Scripts/` | runtime scripts |
| `Assets/Editor/QuarrySceneBuilder.cs` | URP setup, truck prefabs, scene |
| `Assets/Editor/PlayerBuilder.cs` | macOS player build (Tools > Mining > Build macOS Player), output `Builds/mac/Quarry.app` |
| `Assets/Editor/SceneCapture.cs` | renders sensor cameras and inspection views to PNG |
| `Assets/Editor/PeopleImporter.cs` | Humanoid rig, looping clips, URP materials for `Models/People` |
| `Assets/Models/People/` | Rocketbox avatars and walk clips (fetched, gitignored) |
| `Assets/Models/Trucks/` | truck GLBs, `CREDITS.md` |
| `Assets/MineSim/` | world importer (Tools > Mine Sim), road graph, `MineGroundFollow`, cinematic look ([README](Assets/MineSim/README.md)) |
| `Packages/manifest.json` | URP, glTFast, particle system and terrain physics modules |

## Scripts

| Script | Attach to |
|---|---|
| `BrainClient.cs` | one empty GameObject |
| `TruckAgent.cs` | truck root (kinematic Rigidbody) |
| `SensorCamera.cs` | truck front camera, overview camera |
| `LidarSensor.cs` | truck child transform at the sensor mount |
| `PedestrianWalker.cs` | pedestrian root (CapsuleCollider, kinematic Rigidbody); `path` = parent of waypoint transforms |
| `BrainProtocol.cs` | none |
