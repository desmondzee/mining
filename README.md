# Physical Mining: a voice-dispatched autonomous mine

An autonomous open-pit mine you run over the radio. The operator keys the mic and speaks a plain-English order ("all trucks haul North Bench to the crusher"). **ElevenLabs** transcribes it, an **LLM dispatcher** turns it into tool calls (`assign_haul`, `go_to`, `hold`, `avoid_site`, ...), and a fleet of haul trucks replans with **A\*** on a terrain nav grid, drawing the faint "imagined" ghost routes the planner considered before committing. Each truck answers in its own ElevenLabs voice. The mine is generated by **World Labs Marble** (Gaussian splat + collider), with a procedural fallback that needs no API keys. Click any truck to open a live driver's-eye view from **Reactor LingBot World 2**, a world model steered by that truck's drive intent.

The integration contract between all parts is in [CONTRACT.md](CONTRACT.md).

## Architecture

```
 Browser (React + three.js / r3f)
   |  mic (MediaRecorder, needs HTTPS)        click truck -> Reactor JWT -> LingBot World 2 stream
   v
 [ Caddy :443 (profile tls) | cloudflared (profile tunnel) ]   optional HTTPS front
   v
 nginx  (web container, :80 -> host ${WEB_PORT:-8080})
   |-- /            SPA (web/dist)
   |-- /api/*  ---->+
   |-- /worlds/* -->+--> FastAPI server :8000 (server container)
   '-- /ws  ------->+       |-- STT / TTS ............ ElevenLabs
                            |-- dispatcher (tools) .... OpenAI-compatible LLM (regex fallback)
                            |-- sim + fleet + A* ...... 10 Hz state over /ws (paths + ghost_paths)
                            |-- /api/reactor/token .... Reactor (key stays server-side)
                            '-- data/worlds/<id>/  <--- envgen (procedural | World Labs Marble)
```

## Quickstart: local dev

```bash
# 1. Generate the default world (no keys needed)
python3 -m venv .venv && source .venv/bin/activate
pip install -r envgen/requirements.txt
python -m envgen.procedural --seed 42 --id default        # -> data/worlds/default/

# 2. Server
pip install -r server/requirements.txt
cp deploy/.env.example deploy/.env    # optional: add keys
cd server && DATA_DIR=../data uvicorn app.main:app --reload --port 8000

# 3. Web (separate terminal; Vite dev server proxies /api, /ws, /worlds to :8000)
cd web && npm ci && npm run dev
```

Open the Vite URL on `localhost`. Browsers treat localhost as a secure context, so the mic works without HTTPS.

## Quickstart: Docker deploy (Linux server)

```bash
cd deploy
cp .env.example .env            # fill in whichever keys you have; all are optional
docker compose --profile tools run --rm envgen python -m envgen.procedural --seed 42 --id default
docker compose up -d --build    # http://<server>:8080
docker compose logs -f server
```

Optional Marble world (needs `WLT_API_KEY`):

```bash
docker compose --profile tools run --rm envgen python -m envgen.worldlabs --help
```

Compose v2.24+ is required (the `.env` file is marked optional).

### HTTPS (required for the microphone)

Browsers only allow `getUserMedia` on HTTPS or localhost. Pick one:

1. **Caddy with a domain.** Point a DNS A record at the server, set `DOMAIN=mine.example.com` in `deploy/.env`, open ports 80 and 443, then:
   `docker compose --profile tls up -d --build` and open `https://mine.example.com`.
2. **Cloudflare quick tunnel** (no domain, no open ports):
   `docker compose --profile tunnel up -d --build`, then `docker compose logs tunnel | grep trycloudflare` for the `https://*.trycloudflare.com` URL.
   Without Docker: `cloudflared tunnel --url http://localhost:8080`.
3. **Localhost on the demo laptop.** Run the stack (Docker or dev) on the laptop you present from and open `http://localhost:8080`.

If the mic is unavailable, you can still type commands in the radio panel.

### Multi-arch builds (amd64 + arm64)

All images use multi-arch bases (`python:3.12-slim`, `node:20-alpine`, `nginx:alpine`). The node build stage runs on the build host's native platform, so it is never emulated. To cross-build from an Apple Silicon Mac for an amd64 server:

```bash
docker buildx create --use --name mine-builder
# from repo root
docker buildx build --platform linux/amd64,linux/arm64 -f deploy/server.Dockerfile -t <registry>/mine-server:latest --push .
docker buildx build --platform linux/amd64,linux/arm64 -f deploy/web.Dockerfile    -t <registry>/mine-web:latest    --push .
# or, for one platform, load locally and ship it:
docker buildx build --platform linux/amd64 -f deploy/server.Dockerfile -t mine-server --load .
docker save mine-server | ssh server docker load
```

The simplest approach is to `git clone` on the server and run `docker compose up --build` there.

## Environment variables (`deploy/.env`)

| Variable | Required | Purpose | If missing |
|---|---|---|---|
| `OPENAI_API_KEY` | no | LLM dispatcher (function calling) | regex/keyword parser |
| `OPENAI_BASE_URL` | no | OpenAI-compatible gateway, e.g. Vercel AI Gateway | api.openai.com |
| `OPENAI_MODEL` | no | Dispatcher model | `gpt-4.1-mini` |
| `ELEVENLABS_API_KEY` | no | Speech-to-text and truck voices | `audio_url: null`, browser speechSynthesis, typed commands |
| `ELEVENLABS_VOICE_IDS` | no | Comma-separated voice IDs, one per truck; dispatch uses the first | default voice |
| `REACTOR_API_KEY` | no | Server exchanges it for a Reactor JWT (LingBot World 2) | panel shows "stream unavailable" |
| `WLT_API_KEY` | no | World Labs Marble generation (envgen only) | use the procedural world |
| `DATA_DIR` | no | World directory inside containers | `/app/data` |
| `WEB_PORT` | no | Host port for nginx | `8080` |
| `DOMAIN` | for `tls` | Public hostname for Caddy auto-HTTPS | `localhost` |

## Demo script

Key the mic (or type) and say these in order:

1. **"Dispatch to all trucks, status report."** Each truck answers in its own voice.
2. **"Trucks one and two, haul North Bench to the crusher, five loads."** Routes appear, with faint ghost alternatives the planner imagined.
3. **"North pit is flooding, avoid North Bench."** The area becomes impassable and trucks replan live.
4. **"Truck three, go to the fuel bay."** Then click Truck 3 to open the Reactor driver's-eye stream.
5. **"All trucks hold."** Then: **"Resume, everyone haul East Bench to the crusher."**
